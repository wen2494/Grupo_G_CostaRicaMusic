Coloca aqui los archivos que quieres usar en el reproductor.

Rutas recomendadas para `Grupo_G_API/Data/music-catalog.json`:

- Canciones: `/media/audio/nombre-cancion.mp3`
- Portadas de albumes: `/media/images/albums/nombre-album.jpg`
- Imagenes por cancion: `/media/images/songs/nombre-cancion.jpg`
- Imagenes de artistas: `/media/images/artists/nombre-artista.jpg`

En cada cancion puedes usar `UrlImagen` para mostrar una imagen diferente a la portada del album. Si `UrlImagen` queda en `null`, el reproductor usa `UrlPortada` del album.
